What each stage does

Ingest

Run when data lands

Himawari every 10 min · IMERG every 30 min · BMKG every 3 h

Dagster sensors check for the next file and start the chain the moment it exists. Himawari comes as raw Band 13 from NOAA's public AWS bucket, about 12 min after each scan, and only the 2 or 3 segments over Indonesia are read. NASA's OPeNDAP service crops IMERG Early to the Indonesia box. BMKG runs on a schedule and skips runs it already has, using analysis_date. BMKG does not publish past runs, so every run is archived from day one to score it.

Bronze

Short raw window

Cropped to the Indonesia box

Retention caps vary by source. The storage chart shows the limits from the API.

Silver

Summaries per area

PySpark for history · DuckDB live

cloud_kabkota holds the coldest cloud top and cold-cloud share per area every 10 min. rain_kabkota holds mean, max cell and wet share per area per 30 min. grid_cells keeps 30 days of land cells. Optical flow on the Band 13 field moves today's cold cloud forward and stores the expected cold-cloud share per area at +1, +2 and +3 h. gauge_hourly turns GHCNh airport weather codes into rain yes/no, as an independent check on IMERG.

Gold

Built for the app

after each silver update

map_frames has one row per area, slot and layer for the last 7 days, so the slider never waits. features is built when the model needs it and never written to disk.

Model

Train weekly, score every slot

LightGBM · +1, +2, +3 h

Spark builds the training rows and LightGBM trains on one node. It trains on IMERG Early history, the same product that arrives live, and retrains when NASA moves Early to V08. Fresh Himawari cloud tops and their motion cover the time before IMERG arrives. Predictions are stored before the truth exists, so the scoreboard is fair.

Serve

Map-first web app

FastAPI + DuckDB · MapLibre GL JS

The API reads archived frames from Parquet. Cloud frames are served as small WebP images that the browser tints in the gruvbox palette.
